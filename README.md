# SumaiBoard（すまいボード）

SumaiBoard は、オーナーから委託を受けた物件の運営を扱う賃貸管理業務システムです。管理会社の担当者が物件・部屋の登録から入居、家賃収納、修繕、オーナー精算までを追い、オーナーはマイページで自分の物件や精算を確認できます。

## 主な機能

- 管理業務ダッシュボードで当月請求分の未収、未消込入金、精算承認待ち、緊急の修繕・苦情を確認
- 物件・部屋、オーナー、管理委託契約、管理料プランの管理
- 入居申込の受付・審査、賃貸借契約、入居・退去の記録
- 月次請求の生成、入金の記録と消込、滞納・敷金の管理
- 修繕・苦情の受付、見積・承認・手配、検収、費用確定
- 実収納・消込済みの金額に基づくオーナー精算、承認、模擬送金、分別管理台帳
- オーナーマイページで管理対象の物件、修繕履歴、確定済み精算を閲覧

## 共有サンプル環境

公開サンプルにはゲストとして入場できます。すべてのデータは架空で、業務データは来訪者間で共有されます。操作結果は毎日 04:10（日本時間）の自動リセットで初期状態に戻ります。個人情報や実際の取引情報は入力しないでください。

本システムは外部サービスの利用を想定したデモです。実際の API 連携・電子署名・送金は行っていません。外部手続きの状態はサンプルの記録であり、送金の登録・実行はすべて模擬操作です。

面接での操作順は [面接デモ操作ガイド](docs/demo-guide.md) を参照してください。

## 技術構成と開発環境

React と Vite のフロントエンドを FastAPI と同じアプリコンテナで配信します。MySQL 8 は別コンテナで稼働し、データは Docker の名前付きボリュームに保存します。

開発用の専用サンプル DB で起動するには、リポジトリのルートで実行します。

```sh
docker compose -f docker-compose.dev.yml up -d --build
```

起動後は `http://127.0.0.1:18083/` を開きます。公開環境の配備手順とデータ分離の詳細は [DEPLOY.md](DEPLOY.md) と [公開サンプルのデプロイ境界](docs/sample-deployment-boundary.md) を参照してください。

# 面接デモ操作ガイド

共有サンプルでは、入力例を含めすべて架空のデータを使います。外部サービスの利用を想定したデモです。実際の API 連携・電子署名・送金は行っていません。

## ゲスト入場から賃貸借契約まで

1. 公開サンプルを開きます。未ログインの場合はゲストとして入場し、「管理業務ダッシュボード」が開きます。画面の「共有サンプル環境」と SAMPLE 表示を確認します。
2. ダッシュボードで、当月請求分の未収額・件数、未消込入金、精算承認待ち、緊急の修繕・苦情を確認します。各カードから対応する業務画面を開きます。「家賃収納」の「請求」では、当月の各請求の未収額と状態を確認できます。
3. 「物件・部屋」で「建物」から「サンプル物件 01」を開きます。「部屋」で 101 号室の入居状態・現行契約を確認し、「管理契約」でオーナー A の `MC-01-101` を確認します。
4. 「申込・契約」で受付済みの `APP-01` を開きます。当月の請求まで実演する場合は「編集」で入居希望日を当日に設定してから、「審査を開始」→「承認」と進めます。この申込は、F03 用の 101 号室とは別の管理対象の部屋に紐づいています。承認済みの申込で「契約を作成」を選び、部屋と申込内容が引き継がれることを確認します。
5. 作成した賃貸借契約で「署名日を記録」→「入居を記録」と進め、「物件・部屋」で入居状態を確認します。「外部手続き記録」にはサンプル上の手続き状態が表示されます。

## 家賃収納から修繕まで

6. 「家賃収納」→「請求」で所属月を選び、「月次請求を生成」を押します。新規入居分の家賃・共益費と生成件数を確認します。同月に生成済みの請求はスキップされます。F03 用の 101 号室には当月の請求・消込が用意されています。
7. 「入金」で実演用の別契約を選び、架空の支払者・入金額・預り金口座で「入金を登録」します。「消込」で入金と対象請求を選び、双方の残額を確認して「消込を登録」します。家賃と共益費を別々に消し込む場合は、残額を確認して二つ目の請求にも登録します。
8. 「修繕・苦情」→「修繕」で `WO-F03` を開き、オーナー負担の実費 12,000 円、検収、費用確定を確認します。別の受付済み修繕で流れを実演する場合は「見積を記録」→「承認」→「手配」→「作業完了」→「検収」→「費用確定」の順に進めます。

## F03 の精算・模擬送金とオーナー確認

9. ヘッダー右上のアカウントメニューから経理（`FN-01`）に切り替え、「オーナー精算」を開きます。当月と `MC-01-101` を選んで「精算を生成」を押します。対象月の精算がすでにある場合は一覧から開きます。
10. 精算詳細の「収納額」85,000 円（家賃 80,000 円＋共益費 5,000 円）、「管理料控除」4,250 円（5%・税込）、「修繕控除」12,000 円、「模擬送金予定額」68,750 円を確認します。明細から消込記録と修繕記録を開けます。敷金 80,000 円は分別管理台帳の預り金内訳で確認できます。
11. 経理で「提出」し、アカウントメニューから別の模擬担当者である社長（`EX-01`）に切り替えて同じ精算を「承認」します。経理に戻して「確定」し、模擬送金予定日を指定して「模擬送金を予定」→「模擬送金を実行」と進めます。「模擬送金済み」と実績 68,750 円を確認します。
12. アカウントメニューからサンプルオーナー A（`OW-A`）に切り替えます。「オーナーマイページ」→「確定済みの精算」で同じ月・同じ `MC-01-101` の精算詳細を開き、収納・控除・模擬送金額が管理画面と一致することを確認します。

## 操作をやり直す

画面が古い場合は再読み込みし、対象月・契約・模擬アカウントを確認します。共有サンプルの業務データは毎日 04:10（日本時間）の自動リセットで復元されます。ほかの来訪者の操作でサンプルの状態が変わっていた場合は、リセット後に開き直します。運用担当者は、公開サンプル専用の配備先で `reset-sample.sh` を実行して初期状態を復元できます。
